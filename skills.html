01 / CAPABILITYSYSTEM / NETWORK

系统管理与网络工程

能管理 Windows 和 Linux 上的账户、权限、进程与服务，搭建虚拟机实验网络。理解 TCP/IP、ARP、ICMP、子网、交换与路由，能配置 VLAN 并排查连通性。

动手重点
账户、权限与服务状态一起核对；用 分层排查 区分地址、路由与应用故障。
验证方式
保留拓扑、配置和抓包结果，复测同网段与跨网段访问。

Python 编程与网络工具

能用 Python 处理文件和结构化数据，使用线程、进程和协程组织并发任务。能用 Socket 编写网络程序，并用 Scapy、PyDivert 和 mitmproxy 分析实验流量。

05 / CAPABILITYWEB / VULNERABILITY

Web 渗透测试与漏洞挖掘

能在授权范围内梳理资产和接口，验证 SQL 注入、XSS、CSRF、SSRF、文件上传与反序列化风险。能比较不同角色和业务状态下的请求，识别越权、验证码和并发逻辑问题，整理复现步骤与修复建议。

动手重点
先梳理角色、对象和业务状态，再追踪 可控输入与权限边界。
验证方式
让复现步骤、请求差异、影响与修复复测相互对应。
Burp SuiteSRC / EduSRC业务逻辑漏洞报告

源码审计与组件安全

动手重点
沿路由到敏感操作追踪数据流，核对 校验、鉴权和危险调用 的真实条件。
验证方式
用最小样例验证判断，记录调用链、修复点和回归结果。

08 / CAPABILITYCTF / BINARY

CTF 与二进制分析

能按 Web、Misc、Crypto、Reverse、Pwn 方向拆解题目，用 IDA 和 GDB 结合静态与动态分析。理解 RSA、对称密码、栈与堆漏洞、格式化字符串和 ROP，并能组织题解赛与攻防赛的靶场练习。

动手重点

验证方式

AI Agent 与安全评估
